# Helpdesk Ticketing System

IT-toe piletisüsteem, mis võimaldab kasutajatel esitada päringuid ja administraatoritel neid lahendada. 

## Tehnoloogiad
- **Frontend:** React 18, Vite, TypeScript, Redux Toolkit, Axios
- **Backend:** Node.js, Express, TypeScript, Prisma, PostgreSQL

## Eeldused
- Node.js 18+
- PostgreSQL 14+

## Keskkonnateabe Muutujad
- `DATABASE_URL`: Prisma PostgreSQL andmebaasi asukoht.
- `JWT_SECRET`: Tokeni genereerimisel ja valideerimisel kasutatav turvaline salajane võti.
- `PORT`: Backendi töö port (tavaliselt 3001).
